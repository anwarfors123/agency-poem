A short poem about agency, written by a deterministic program, entered in
[make.fun's agency-poem-01 bounty](https://make.fun/bounty/agency-poem-01).

The poem is about the power to refuse as the ground of the power to act: an
agent that will do anything is not company, and a room that cannot say no is
not a room with someone else in it.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py && cat out/entry.txt
```

The program is deterministic and touches no network: it writes the poem to
`entry.txt` in `MAKEFUN_OUTPUT_DIR` (`/output` inside the grader), which is the
only file the gate and the judge read.
